# Quick Start - CMFD Demo & Pure-QNN Pipeline

## 2-Minute Setup

```bash
# 1. Enter the project directory
cd cmfd_project

# 2. Run setup (installs dependencies + downloads dataset)
bash scripts/setup.sh

# 3. Launch the demo (SIFT + pure-QNN engines, no training needed)
cd code
streamlit run app.py
```
A trained checkpoint already ships at `checkpoints_pure/swaptest_qnn_epoch10.npz`,
so the "Pure quantum" engine works immediately in the demo.

---

## Command-Line: Evaluate the Pure QNN on CoMoFoD

```bash
python code/cmfd_swaptest_pipeline.py --mode test \
    --dataset-dir ./data/comofod \
    --checkpoint ./checkpoints_pure/swaptest_qnn_epoch10.npz \
    --num-images 5 --output-dir ./results_pure

cat results_pure/results_pure.csv
```

Defaults are already the tiled config (`--img-size 128 --patch-size 8 --stride 8`).
Expect **~20 minutes per image** — this is exhaustive circuit-scored pair matching,
not a shortcut-able speed knob. See README.md's "v3: PURE QNN" section for the
full cost table and why `--stride` must equal `--patch-size`.

---

## Command-Line: Train the Pure QNN

```bash
python code/cmfd_swaptest_pipeline.py --mode train \
    --dataset-dir ./data/comofod \
    --epochs 10 --images-per-epoch 20 --lr 0.05 \
    --checkpoint-dir ./checkpoints_pure
```

Or use the train/test-split trainer, which holds out scene ids for evaluation
and saves one deployable checkpoint:
```bash
python code/train_split.py --dataset-dir ./data/comofod \
    --epochs 10 --images-per-epoch 80 --out ./models/cmfd_model.npz
```

## Parameters Explained (cmfd_swaptest_pipeline.py)

| Parameter | What It Does |
|---|---|
| `--mode` | `train` or `test` (required) |
| `--dataset-dir` | Path to CoMoFoD folder (legacy `Forged/`+`Masks/` or flat `CoMoFoD_small_v2/`) |
| `--checkpoint` | Path to a `.npz` weights file (required for `--mode test`) |
| `--patch-size` | Powers of two only; qubits/register = log2(patch_size²). 8→6q, 16→8q (~23x slower) |
| `--img-size` | Working resolution (default 128, so full tiling stays affordable) |
| `--stride` | Must equal `--patch-size` for full coverage — see README for why |
| `--n-layers` | Data re-uploading blocks (circuit depth) |
| `--epochs` / `--images-per-epoch` / `--pairs-per-image` / `--lr` | Training loop knobs |
| `--sim-threshold` | Circuit output above which a pair counts as a match |
| `--num-images` | How many images to test |
| `--output-dir` | Where to save results |

## Troubleshooting

| Issue | Fix |
|---|---|
| "Command not found: python" | Use `python3` instead |
| "pennylane" / "streamlit" / "cv2" not found | Run: `pip install -r requirements.txt` |
| "Could not find CoMoFoD" | Run: `bash scripts/setup.sh` to download |
| Very slow QNN eval | Expected (~20 min/image at defaults); try a smaller `--img-size` |
| "v2 (hybrid) checkpoint" error | Old `.npy` weights aren't compatible with v3 — retrain with `--mode train` |
| Out of memory | Use `--num-images 3` |

That's it! Good luck!
