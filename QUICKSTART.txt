# Quick Start - CoMoFoD CMFD Testing

## 2-Minute Setup

```bash
# 1. Extract ZIP and enter directory
unzip cmfd_project.zip
cd cmfd_project

# 2. Run setup (installs dependencies + downloads dataset)
bash scripts/setup.sh

# 3. Run quick test (5 images)
python code/cmfd_comofod_pipeline.py --dataset-dir ./data/comofod --num-images 5

# 4. Check results
cat results/results.csv
ls results/*.png
```

---

## Commands by Speed

### FAST (3 images, 15 mins)
```bash
python code/cmfd_comofod_pipeline.py \
    --dataset-dir ./data/comofod \
    --num-images 3 \
    --stride 8 \
    --n-qubits 4 \
    --output-dir ./results_fast
```

### BALANCED (10 images, 50 mins)
```bash
python code/cmfd_comofod_pipeline.py \
    --dataset-dir ./data/comofod \
    --num-images 10 \
    --stride 4 \
    --n-qubits 5 \
    --output-dir ./results
```

### HIGH-QUALITY (20 images, 3 hours)
```bash
python code/cmfd_comofod_pipeline.py \
    --dataset-dir ./data/comofod \
    --num-images 20 \
    --stride 2 \
    --n-qubits 6 \
    --output-dir ./results_hq
```

## Parameters Explained

| Parameter | What It Does |
|---|---|
| `--dataset-dir` | Path to CoMoFoD folder (with Forged/ and Masks/) |
| `--num-images` | How many images to test |
| `--stride` | Patch step size (4=balanced, 8=fast, 2=slow) |
| `--n-qubits` | Quantum circuit size (4-6 recommended) |
| `--n-layers` | Circuit depth (1-3 layers) |
| `--output-dir` | Where to save results |
| `--start-idx` | Skip first N images (for resuming) |

## Troubleshooting

| Issue | Fix |
|---|---|
| "Command not found: python" | Use `python3` instead |
| "pennylane not found" | Run: `pip install -r requirements.txt` |
| "Could not find CoMoFoD" | Run: `bash scripts/setup.sh` to download |
| "Very slow" | Use `--stride 8 --n-qubits 4` |
| "Out of memory" | Use `--num-images 3` |
