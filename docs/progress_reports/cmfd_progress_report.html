§1

What went wrong

A 5-epoch training smoke test showed a loss that never decreased. Rather than assume it just needed more epochs, the gradient was measured directly.

● Critical — root cause

The tied weights were mathematically invisible to the swap test

Both quantum registers were embedded with fixed data, then the same unitary U(w) was applied to both before the swap test read out their overlap. For any unitary, that overlap reduces algebraically to the raw input overlap — the weights cancel out completely, everywhere in parameter space:

|⟨U(w)f_a | U(w)f_b⟩|² = |⟨f_a| U†(w)U(w) |f_b⟩|² = |⟨f_a|f_b⟩|² for ANY U(w)

Confirmed empirically two ways: the measured gradient was ~6.5×10⁻¹⁶ (zero to machine precision) at every qubit count tested, and five independent random weight settings produced the exact same similarity score — matching the raw classical cosine similarity of the input features, bit for bit.

The fix

✓ Resolved — data re-uploading

Weights and data now interleave inside the same gates

Instead of a fixed embedding followed by a data-independent weight block, the trainable weights and each register's own classical features are now combined additively inside the same rotation gates, repeated across layers. Because register A and register B carry different data at every layer, there's no shared data-independent unitary left for the swap test to cancel against. Tied weights and the swap-test readout — both flagged as deliberate — are unchanged.

Training runs

Three runs, same fixed architecture, increasing scale. Raw per-epoch loss stays noisy in all of them — each epoch redraws a random image sample, so batch noise dominates at these run sizes. The shared y-axis below makes the level shift visible: pre-fix hovers near 0.40–0.46 with no possible mechanism to move (the gradient was zero); post-fix runs settle lower, around 0.30–0.35.

The cleaner signal is held-out separation — positive vs. negative pair scores on a fixed synthetic validation batch the model never trains on — measured across the full 10-epoch / 60,000-pair run:

Separation climbs steadily (real signal) — but pairwise rank accuracy, arguably the metric that matters more, stays flat at the random-init baseline. Training is pushing negative-pair scores down on average without becoming better at ranking any specific pair correctly. Reported as-is, not smoothed over.
