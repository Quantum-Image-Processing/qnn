1. Executive Summary

This report documents the current state of a quantum-machine-learning pipeline for copy-move forgery detection (CMFD) — detecting regions of an image that have been duplicated and pasted elsewhere in the same image. The system pairs a classical patch descriptor with a Siamese swap-test quantum neural network (QNN) that learns a similarity score between two image patches, followed by a spatial offset-consistency filter that keeps only genuine duplications.

Headline finding. The pipeline is a genuine end-to-end quantum model, and it does not work as a detector. Both halves of that sentence are measured, not asserted:
  • The trained circuit scores AUC 0.883 against 0.887 for a parameter-free classical cosine similarity — no quantum advantage, at ~36 ms/pair versus microseconds.
  • Training moves AUC by 0.003 (0.880 untrained → 0.883 trained). The 58 rotation angles influence the output less than the choice of input image does.
  • Best achievable detection is F1 0.0813 against a 0.0771 baseline of marking every pixel forged — and that is with an oracle per-image threshold.
Root cause. The classical offset-consistency vote removed in v3 was not scaffolding around the quantum model — it was the component performing the detection. Patch similarity alone drowns in natural self-similarity; a duplicated region is a small signal among tens of thousands of genuinely similar patch pairs. See §7.
v3 finding — the reported non-convergence was a data bug, not a model bug. Training loss was previously stuck at ~0.33, above the 0.25 constant-predictor floor, and this was attributed to the model. The actual cause was in synthetic pair construction: positives were rotated 90/180/270° three times out of four. A swap test compares amplitude vectors, so a rot90 duplicate permutes the state into a near-orthogonal one — measured: an exact rot90 copy scores ~0.01 where an exact copy scores ~1.0. Labelling those pairs 1.0 asks the circuit to fit a target its translation-only architecture provably cannot represent. With rotations excluded, loss drops to ~0.003–0.10, far below the floor. Rotated positives remain available behind --train-rotations and should only be re-enabled together with a dθ component in the offset register.
Status of §6–§10. The results, gap analysis, recommendations and roadmap below were produced with the v2 hybrid and have not yet been re-run against v3. They are retained as the v2 baseline for comparison. Treat every number in them as v2 until the v3 evaluation is complete; v3 is expected to score lower, since removing the offset vote removed the stage that actually suppressed false matches.

2. Objective & Target Output

The intended end product: given any input image, decide whether it is forged, and if so, localize the exact duplicated region as a bounding box or heatmap. That decomposes into four capabilities, tracked in the gap analysis (§8).

3. System Architecture (v3 — pure QNN)

The architecture is a pairwise similarity model, which is the structurally correct choice for copy-move (the task is inherently “does patch A match patch B elsewhere?”). A single-patch classifier cannot express duplication.

v3 removes every classical detection stage from the v2 hybrid. v2 was quantum only in its similarity readout: a classical DCT descriptor decided what the circuit was allowed to see, a classical sort decided which pairs it was allowed to score, and a classical Hough vote decided which of its outputs to believe. In v3 raw pixels enter the circuit and a measured expectation value is the decision.

Do not “simplify” the ansatz. A plain amplitude embedding followed by a data-independent tied unitary is provably degenerate under a swap test: |⟨U(w)fA|U(w)fB⟩|² = |⟨fA|fB⟩|² for any U(w), so the gradient w.r.t. w is exactly zero. This was measured, not assumed: gradient norm ~1e-16 in the degenerate form vs ~1.2e-2 with data re-uploading. Re-uploading the pixels into the rotation angles is what keeps the tied weights alive.

Cost of purity. Removing the classical prefilter makes pair scoring O(N²), so stride is now the dominant cost dial: ~1 min/image at stride 32, ~20 min at stride 16, ~5 h at stride 8. The quantum replacement for the prefilter is Grover/amplitude amplification over a pair-index register, which requires QRAM to hold all patches in superposition — not simulable at this scale, so it is recorded as future work rather than substituted with a classical stand-in.

Known weakness, stated plainly. The offset register is a weaker mechanism than the vote it replaced, not an equivalent one. Offset consistency is a global property of the pair ensemble (“many pairs share one offset”); a per-pair circuit cannot observe clustering it is never shown. A faithful quantum version needs quantum counting over all pairs at once. Expect more false positives on homogeneous regions (sky, walls) than v2 produced.

5. Evaluation Methodology — why not accuracy?

Forged regions occupy only ~2–11% of pixels, so the pixel classes are extremely imbalanced. Under this imbalance, plain accuracy is actively misleading: a model that predicts “nothing is forged” scores ~90–98% accuracy while detecting zero forgeries.

MetricDefinitionMeaning here
Accuracy(TP+TN) / allMisleading — rewards predicting nothing
RecallTP / (TP+FN)Fraction of true forged pixels found. Gamed by flagging everything → this is the “80%” trap
PrecisionTP / (TP+FP)Of the pixels flagged, how many were actually forged
F12·P·R / (P+R)Honest single scalar — collapses if precision OR recall is bad
IoU (Jaccard)TP / (TP+FP+FN)Localization overlap — directly measures “does the predicted region match the true region?”
Reporting rule for this project: lead with F1 and IoU; cite precision+recall as the pair that explains F1; never headline accuracy. IoU is literally the metric that measures the stated goal (exact forged area).

6. Results — pure QNN

Three questions were tested separately, because they have different answers: does the model learn, does the quantum circuit beat a classical equivalent, and does the system detect copy-move forgery.

6.1 Does training improve the model? No.

Two training runs, both on the pure architecture:

RunSynthetic positivesLoss trajectoryInterpretation
A (10 epochs × 80 img)pixel-identical copies0.047 at epoch 1, flat thereafterNothing to learn — a swap test returns ~1.0 for identical states with no trained parameters, so the model starts at the answer
B (11 epochs × 200 img)degraded + feathered0.158 → 0.178, no downward trendA real loss surface, but the weights cannot descend it

Run B was tested with both plain gradient descent and Adam at identical settings and seed. The two trajectories agreed to within 0.002 per epoch and final AUC differed by 0.005 — so the optimizer is not the limitation.

Why the weights cannot help. Varying the 58 rotation angles across independent random draws changes a pair's score by σ = 0.117. Varying the input data changes it by σ = 0.138. The parameters inject almost as much variation as the image content does — they behave closer to noise than to a learned function.

6.2 Does the quantum circuit beat a classical equivalent? No.

Measured on 200 synthetic pairs (100 positive, 100 negative), reporting AUC — the probability that a true duplicate outscores a non-duplicate, where 0.5 is chance:

ScorerAUCTrainable parameters

This is structural, not a tuning failure. A swap test measures |⟨ψA|ψB⟩|². On amplitude-encoded raw pixels that quantity is squared cosine similarity — fixed and parameter-free. The data re-uploading layers exist only to escape the provable degeneracy described in §3, and they buy trainability by scrambling the encoded states, which can only move the measured overlap away from the informative one. The architecture therefore faces a genuine dilemma: untrainable and accurate, or trainable and slightly worse.

7. Key Finding — the classical vote was doing the detection

Mean best-case F1 is 0.0813 against a trivial baseline of 0.0771. Stripped of every classical stage, the system does not detect copy-move forgery. It is statistically indistinguishable from marking the entire image as forged.

Mechanism. Patch similarity alone cannot identify duplication. In any natural photograph tens of thousands of 8×8 patch pairs are genuinely similar — sky, foliage, brickwork, smooth gradients. A copied region is a small signal inside that flood, and a per-pair similarity score has no way to tell a duplicate from a coincidental look-alike.

The offset-consistency vote removed in v3 existed precisely to solve this: a genuine duplication produces many pairs sharing one (dy, dx) offset, whereas coincidental matches scatter across all offsets. It was not scaffolding around the quantum model — it was the component performing the detection.

The in-circuit offset register (§3) cannot substitute for it, and the reason is structural rather than incidental: offset consistency is a global property of the pair ensemble (“many pairs agree on one offset”), and a circuit that sees one pair at a time cannot observe clustering it is never shown. A faithful quantum replacement needs quantum counting or amplitude estimation across all pairs simultaneously, which requires QRAM and is not simulable at this scale.

9. Interpretation

This is a negative result with an identified mechanism, which is a stronger scientific outcome than an unverified claim of quantum advantage. The contribution is not a working detector; it is a controlled demonstration of which component of a quantum-assisted CMFD pipeline was carrying the detection, established by removing every classical stage and measuring what remains.

Three findings generalise beyond this project:

  1. A swap test on amplitude-encoded data is a fixed similarity measure. Any variational structure wrapped around it either cancels (degenerate, zero gradient) or perturbs the encoding away from the quantity that carried the signal. Trainability and fidelity are in tension by construction, not by implementation choice.
  2. Self-supervised pair synthesis silently determines what is learnable. Two separate label-noise bugs — rotated positives, and feathering applied to patch-sized pastes — each created targets the architecture provably could not represent, and each produced a loss curve that looked like model failure rather than data failure.
  3. Per-pair scoring cannot express ensemble-level evidence. Copy-move detection depends on agreement across matches, which is invisible to any model evaluating one pair in isolation.

10. Future work

  1. Quantum offset consistency — the honest replacement for the classical vote is quantum counting / amplitude estimation over a pair-index register, requiring QRAM to hold all patches in superposition. This is the single change that would make a pure quantum detector viable, and it is out of reach of statevector simulation at useful image sizes.
  2. Rotation invariance — add a dθ component to the offset register. A rot90 duplicate currently scores ~0.01 where an exact copy scores ~1.0, so rotated CoMoFoD forgeries are missed entirely.
  3. Larger working resolution — at 128 px a 2%-area forgery spans only ~4 patches, and copy-move requires a matched pair. Exhaustive scoring is O(N²), so 256 px costs ~5 h/image against ~20 min at 128 px.
  4. Grover-based candidate search — would restore the O(√N) advantage lost when the classical prefilter was removed. Same QRAM prerequisite as (1).
Honest summary. The architecture is correct, complete, and measured. It is not a forgery detector, and the measurements above identify exactly why.
